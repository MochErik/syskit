## 🌟 Included Standalone Local Tools

| Command | Tool Name | Description |
| :--- | :--- | :--- |
| `syskit net` | **[NetPulse](https://github.com/MochErik/netpulse)** | Multi-Target Latency Mesh & Wire-Format DNS Benchmark |
| `syskit sentry` | **[NodeSentry](https://github.com/MochErik/nodesentry)** | Micro-Footprint (<15MB RAM) SBC & Homelab Linux Sentinel |
| `syskit commit` | **[Git-Spark](https://github.com/MochErik/git-spark)** | AI & Offline Heuristic Conventional Commit Assistant |
| `syskit env` | **[EnvGuard](https://github.com/MochErik/envguard)** | Pre-Commit Secret Scanner & `.env.example` Validator |
| `syskit docker` | **[DockerVoid](https://github.com/MochErik/dockervoid)** | Container & Image Storage Reclamation Engine |
| `syskit tunnel` | **[QuickTunnel](https://github.com/MochErik/quicktunnel)** | Instant HTTPS Localhost Exposer for Local Testing |
| `syskit forge` | **[Forge-API](https://github.com/MochErik/forge-api)** | Async Clean Architecture FastAPI Microservice Scaffolder |
| `syskit doctor` | **System Doctor** | Local environment, PATH, and system health verification |

## 🚀 One-Line Installation (Linux & macOS)

Install all tools locally into your terminal with zero configuration:
```bash
curl -sSL https://raw.githubusercontent.com/MochErik/syskit/main/install.sh | bash
```

Or install via `pip`:
```bash
pip install syskit-cli
```
